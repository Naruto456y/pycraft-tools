# 🤖 ai_modules — клиенты нейросетей (PyCraft Tools)

Пакет `ai_modules` собирает клиенты ИИ-сервисов. Сейчас в нём есть один: `GigaChat` (Сбер) в файле `gigachat.py`. Другие провайдеры добавляются рядом отдельными файлами и экспортируются из `__init__.py`.

## 🧩 GigaChat

Класс `GigaChat`: чат с памятью диалога, потоковый ответ, вопросы по картинкам, генерация изображений, загрузка файлов, подсчёт токенов, эмбеддинги и очистка распознанной речи от заиканий и слов-паразитов.

> ⚠️ Нужны свои ключи GigaChat API из кабинета разработчика Сбера. В репозитории их нет и быть не должно.

## 🚀 Установка

```bash
pip install pycraft-tools[ai_modules]   # модуль + requests
```

## 🔑 Доступ

Передайте `client_id` и `client_secret` (или готовый `credentials`) в конструктор либо задайте переменные окружения:

| Переменная | Что это |
|---|---|
| `GIGACHAT_CLIENT_ID` | ID клиента |
| `GIGACHAT_CLIENT_SECRET` | секрет клиента |
| `GIGACHAT_CREDENTIALS` | готовый ключ авторизации (вместо пары выше) |

Токен доступа живёт 30 минут. Класс обновляет его сам и повторяет запрос при ошибке 401.

## 💻 Примеры

```python
from ai_modules import GigaChat

ai = GigaChat(remember=True, system_prompt="Отвечай коротко")

ai.chat("Как дела?")                              # ответ с памятью диалога
for part in ai.chat_stream("Расскажи анекдот"):   # ответ по кусочкам
    print(part, end="")

ai.describe_image("photo.jpg", style="brief")     # описание картинки
ai.ask_image("Сколько людей на фото?", "photo.jpg")
ai.generate_image("рыжий кот в скафандре", save_path="cat.jpg")

ai.clean_speech("я э-э-э хочу пиццу")             # очистка распознанной речи
ai.count_tokens("Привет, мир")                    # токены
ai.get_balance()                                  # остаток токенов
```

| Метод | Что делает |
|---|---|
| `chat()` / `chat_stream()` | диалог, параметры модели, память, картинки и файлы |
| `reset_history()` | очистить память диалога |
| `ask_image()` / `describe_image()` | вопрос по изображению и его описание (`brief`, `detailed`, `alt`, `text`, `objects`) |
| `generate_image()` | создание изображения по тексту |
| `upload_file()` / `list_files()` / `get_file_info()` / `download_file()` / `delete_file()` | файлы в хранилище GigaChat |
| `count_tokens()` / `get_balance()` / `list_models()` / `embeddings()` | служебные функции |
| `clean_speech()` | убрать шум, повторы и слова-паразиты из распознанной речи |

Ошибки API поднимают `GigaChatError` с полями `status_code` и `body`.

## 🔒 Безопасность

- `verify_ssl=False` стоит **по умолчанию**, потому что сертификат Минцифры есть не у всех. Для боевого кода передайте `ca_bundle="путь/к/сертификату.pem"`.
- Ключи храните в переменных окружения или в `.env` (он в `.gitignore`), не в коде.

## ⚠️ Ограничения

- Лимиты Сбера: изображение до 15 МБ, документ до 40 МБ, до 10 картинок в одном запросе.
- Это неофициальная обёртка: если Сбер поменяет API, методы придётся обновить.
